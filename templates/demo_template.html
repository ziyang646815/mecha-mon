// 02 — MECHA DATABASE

机甲图鉴

首批 8 台机甲，覆盖 8 种属性与 6 种战斗定位。每台机甲 4 个专属招式，共 32 个帧数据驱动的 GAS 能力。

// 03 — ELEMENT MATRIX

属性克制拓扑

8 种属性构成动态克制网络。箭头由攻击方指向被克制方（2× 伤害）。悬停任一属性，高亮其克制关系。

◈
单一数据源

机甲/招式/帧窗口全部由 Python 配置驱动，文档、代码、演示三端自动同步。

⚡
帧级判定

60Hz 逻辑帧驱动，前摇/判定/后摇逐帧结算，hitstop 与僵直真实反馈。

⬡
GAS 原生架构

ASC / AttributeSet / CombatAbility / FrameData 分层，C++ 基座可直接导入 UE5。

✦
操作深度

弹反/霸体/取消/连招构成攻防博弈，高操作上限与电竞观赏性。

// 04 — TECHNICAL ARCHITECTURE

技术架构 · UE5 GAS

基于 Unreal Engine 5 的 Gameplay Ability System 构建。招式、帧数据、判定、表现四层解耦，判定与动画分离，天然支持竞技网络同步与数据驱动。

项目路线图
