# MECHA·MON 游戏设计文档（GDD）

> 版本 0.1.0-Prototype · 引擎 Unreal Engine 5 · 技术框架 Gameplay Ability System (GAS)

## 1. 产品概述

**机甲兽竞技场**（MechaMon Arena）是一款以机甲收集与回合制策略对战为核心的竞技游戏。玩家扮演机甲指挥官，组建 3 台机甲的作战小队，通过属性克制、技能组合与能量管理击败对手。

- **一句话定位**：机甲觉醒 · 策略竞技 · 属性压制
- **游戏类型**：回合制策略竞技 / 机甲收集养成
- **目标平台**：PC (首发) / 主机 (后续)
- **核心体验**：收集 → 养成 → 构筑 → 竞技

## 2. 核心玩法循环

```text
登录 → 选择机甲小队 → 匹配对手 → Ban/Pick → 3v3 回合制对战 → 结算段位/奖励
        ↑                                                              ↓
        └──────────── 获得零件 → 改装机甲 → 解锁新技能 ←──────────────┘
```

| 涌流 `WATER` | 烈焰、钢甲 | 森绿、雷霆、涌流 | 高耐久水装甲，克制烈焰与钢甲。 |

## 5. 养成系统

- **核心模块**：机甲等级、装甲强化、武器精通、能源核心（4 条养成线）
- **改装槽位**：每台机甲 3 个模块槽（攻击/防御/功能），通过竞技获得零件
- **技能解锁**：等级 5/10/15/20 依次解锁 4 个技能，避免新手信息过载
- **平衡原则**：养成仅影响数值上限的 ±10%，竞技场采用标准化数值（公平对战）

## 6. 竞技模式

- **对战形式**：3v3 单败淘汰 / 天梯排位
- **队伍规模**：3 台机甲
- **回合上限**：30 回合，超时按剩余装甲百分比判定
- **禁用阶段**：双方各禁用 2 台机甲（BO3 起）
- **段位体系**：青铜 → 白银 → 黄金 → 铂金 → 钻石 → 大师 → 王者

## 7. 与非机甲IP的差异化

1. **能量管理**：技能消耗能量而非传统 PP，引入资源博弈
2. **部位破坏**：重击可破坏机甲部位，降低对应属性（开发中）
3. **换人代价**：换人消耗能量，抑制无脑轮换
4. **电竞友好**：回合制 + 明确克制关系，观赛门槛低、可读性强
