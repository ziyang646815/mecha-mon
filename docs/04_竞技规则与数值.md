## 2. 伤害计算公式

```text
基础伤害 = 技能威力 × (攻击方攻击 / 防御方防御) × 属性克制倍率 × 暴击倍率
属性克制倍率 = 2.0 (克制) / 1.0 (中性) / 0.5 (抵抗) / 0.0 (免疫)
暴击倍率 = 1.5 (基础) + 装备修正
最终伤害 = max(1, floor(基础伤害 × 随机波动(0.95~1.05)))
```

## 3. 行动顺序

1. 按速度属性降序排列（同速时按服务器随机数）
2. 拥有先手标签的技能优先结算
3. 冻结/眩晕状态跳过回合
4. 每回合结束回复 12 点能量（上限 120）

## 5. 平衡性约束

- 共 8 台机甲、32 个技能
- 单台机甲 4 个技能，耗能区间 16~32，CD 区间 0~4
- 属性克制闭环确保无绝对强势属性
- 竞技场采用标准化数值，养成仅影响 ±10%
